3. Як ми використовуємо геолокацію

Геолокація використовується під час активного користування грою, щоб визначати ваше положення на ігровій мапі та розміщувати ігрові об'єкти поруч.

Координати ваших ігрових дій, зокрема місця спавну й збору карток, зберігаються на наших серверах як частина ігрового стану та для захисту гри від зловживань.

На момент альфа-версії фонове відстеження геолокації не використовується — гра отримує ваше положення лише коли відкрита.

У майбутніх версіях планується додати фонові сповіщення про появу нових ігрових точок поруч. Перед увімкненням такої функції ми оновимо цю політику й запитаємо ваш окремий дозвіл.

4. Де зберігаються дані

Дані зберігаються на серверах Supabase, інфраструктура на базі Amazon Web Services, регіон — Європейський Союз. Supabase виступає обробником даних від нашого імені. Передача даних захищена шифруванням HTTPS/TLS.

5. Передача третім сторонам

Ми передаємо дані лише сервісам, потрібним для роботи гри:

  • Supabase — зберігання облікових записів, ігрового прогресу та геоданих.
  • Постачальники картографічних тайлів — для відображення мапи завантажуються зображення мап зі стороннього тайл-сервера; при цьому передається лише запит на ділянку мапи, без ваших персональних даних.

У майбутньому, при додаванні push-сповіщень, буде підключено Google Firebase Cloud Messaging. Ця політика буде відповідно оновлена.

Ми не передаємо ваші дані рекламним мережам чи брокерам даних.
