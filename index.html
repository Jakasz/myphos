3. Як ми використовуємо геолокацію

Геолокація використовується лише під час активного користування грою, коли застосунок відкритий або використовується користувачем.

Myphos використовує поточне місцезнаходження користувача для відображення позиції на ігровій мапі, перевірки близькості до ігрових точок, збору карток, взаємодії з територіями та інших геолокаційних механік.

Ми не зберігаємо постійну історію пересування користувача та не ведемо хронологію маршрутів. Поточна геолокація може передаватися на сервер для перевірки ігрових дій, наприклад перевірки того, чи користувач достатньо близько до ігрової точки. Така перевірка використовується для роботи гри та захисту від зловживань.

На момент альфа-версії фонове відстеження геолокації не використовується — гра отримує ваше положення лише коли застосунок відкритий або активно використовується.

Користувач може будь-коли відкликати дозвіл на доступ до геолокації в налаштуваннях свого пристрою. У такому випадку частина ігрових функцій, пов'язаних із мапою, збором карток і взаємодією з ігровими точками, може працювати обмежено або бути недоступною.

У майбутніх версіях може бути додано фонові сповіщення про появу нових ігрових точок поруч. Перед увімкненням такої функції ми оновимо цю політику й запитаємо окремий дозвіл користувача, якщо такий дозвіл буде потрібний.

4. Правова підстава обробки даних

Ми обробляємо дані користувачів для надання функцій гри, створення та підтримки облікового запису, збереження ігрового прогресу, забезпечення безпеки, запобігання зловживанням, покращення стабільності застосунку, показу реклами та виконання вимог законодавства.

У випадках, коли це потрібно, зокрема для доступу до геолокації або інших дозволів пристрою, обробка здійснюється на підставі згоди користувача, яку він надає через системні дозволи пристрою.

5. Де зберігаються дані

Дані облікового запису, ігровий прогрес та пов'язані ігрові дані зберігаються на серверах Supabase. Supabase використовує інфраструктуру на базі Amazon Web Services. Регіон зберігання даних — Європейський Союз, якщо інше не буде зазначено окремо.

Передача даних захищена шифруванням HTTPS/TLS. Supabase виступає обробником даних від нашого імені.

6. Передача даних третім сторонам

Ми передаємо або надаємо доступ до даних лише сервісам, потрібним для роботи, підтримки, аналітики стабільності або монетизації гри.

  • Supabase — реєстрація та вхід користувачів, зберігання облікових записів, user ID, нікнеймів, ігрового прогресу та пов'язаних ігрових даних.
  • Постачальники картографічних тайлів — для відображення мапи завантажуються зображення мап зі стороннього тайл-сервера. При цьому може передаватися технічний запит на відповідну ділянку мапи.
  • Google Firebase Crashlytics — збір діагностичних даних про збої, помилки та стабільність застосунку.
  • Рекламні сервіси, наприклад Google AdMob або інші рекламні партнери, — показ реклами, вимірювання її ефективності, захист від шахрайства та, залежно від налаштувань, персоналізація або неперсоналізований показ реклами.

Ми не продаємо персональні дані користувачів брокерам даних. Ми також не передаємо користувацькі фото, аудіо, контакти або історію дзвінків, оскільки застосунок не збирає такі дані.
