## 1. Хто ми

Myphos — мобільна геолокаційна гра-колекція, у якій гравець збирає картки
українських історичних діячів, переміщуючись у реальному світі.

З питань конфіденційності звертайтеся: **myph.app@gmail.com**

## 2. Які дані ми збираємо

Ми збираємо лише дані, потрібні для роботи гри:

| Дані | Навіщо |
|---|---|
| **Email-адреса** | Реєстрація та вхід в обліковий запис (через сервіс Supabase Auth). |
| **Нікнейм / ім'я користувача** | Відображення у грі. *(на момент альфа-версії може формуватися автоматично з email; окреме поле буде додано пізніше)* |
| **Геолокація (GPS)** | Основна механіка гри: розміщення карток та ігрових точок поруч із вами, захоплення територій, перевірка близькості при зборі картки. |
| **Ігровий прогрес** | Зібрані картки, території, статистика — щоб зберігати ваш прогрес. |
| **Технічні дані** | Базова діагностика помилок для покращення стабільності. |

Ми **не** збираємо: контакти, фото, мікрофон, історію дзвінків, рекламні
ідентифікатори. Ми **не** показуємо рекламу і **не** продаємо ваші дані.

## 3. Як ми використовуємо геолокацію

- Геолокація використовується **під час активного користування грою**, щоб
  визначати ваше положення на ігровій мапі та розміщувати ігрові об'єкти поруч.
- Координати ваших ігрових дій (місця спавну й збору карток) зберігаються на
  наших серверах як частина ігрового стану та для захисту гри від зловживань.
- На момент альфа-версії **фонове відстеження геолокації не використовується** —
  гра отримує ваше положення лише коли відкрита.
- *(У майбутніх версіях планується додати фонові сповіщення про появу нових
  ігрових точок поруч. Перед увімкненням такої функції ми оновимо цю політику
  й запитаємо ваш окремий дозвіл.)*

## 4. Де зберігаються дані

Дані зберігаються на серверах **Supabase** (інфраструктура на базі Amazon Web
Services, регіон — Європейський Союз). Supabase виступає обробником даних від
нашого імені. Передача даних захищена шифруванням (HTTPS/TLS).

## 5. Передача третім сторонам

Ми передаємо дані лише сервісам, потрібним для роботи гри:

- **Supabase** — зберігання облікових записів, ігрового прогресу та геоданих.
- **Постачальники картографічних тайлів** — для відображення мапи завантажуються
  зображення мап зі стороннього тайл-сервера; при цьому передається лише запит на
  ділянку мапи, без ваших персональних даних.

*(У майбутньому, при додаванні push-сповіщень, буде підключено Google Firebase
Cloud Messaging — ця політика буде відповідно оновлена.)*

Ми не передаємо ваші дані рекламним мережам чи брокерам даних.

Щоб видалити обліковий запис і дані, напишіть на **myph.app@gmail.com** —

облікового запису пов'язані дані видаляються з наших активних систем.
